# BioDC

A Python program that 
automates and accelerates the computation of 
redox potentials, cooperativities, and conductivities 
in (polymeric) multi-heme cytochromes.

## Important Comments
BioDC has three large divisions:
- Structure Preparation and Relaxation (fully Implemented)
- Energetic Evaluation (not fully debugged yet)
- Kinetics Evaluation (not fully debugged yet)

There is a comprehensive command-line interface via:

'''bash
biodc-cli
'''

once you install the package.

There is currently a graphical user interface (GUI) for the 
Structure Preparation and Relaxation division that is accessible by

'''bash
biodc-spr-gui
'''

once you install the package.

GUIs for the other divisions are under development.
